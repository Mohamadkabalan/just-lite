# Self-hosted Google Fonts

Downloaded from fonts.gstatic.com (latin and latin-ext subsets, WOFF2) so the
site no longer loads fonts from Google. The `@font-face` rules are at the top
of `public/css/style.css`.

- Roboto Slab (variable, 100–900): Apache License 2.0, https://fonts.google.com/specimen/Roboto+Slab/license
- DM Sans (variable, 400–700, normal and italic): SIL Open Font License 1.1, https://fonts.google.com/specimen/DM+Sans/license
